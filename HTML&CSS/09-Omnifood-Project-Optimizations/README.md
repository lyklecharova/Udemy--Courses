# Omnifood Project 🍽️

Responsive, modern landing page built with **HTML5** and **CSS3**.  
Part of the **"HTML & CSS" Udemy course** by Jonas Schmedtmann.

---

## 🌐 Live Demo

[View Live Site on Netlify](https://omnifood-project-lk.netlify.app/)  


---

## ✨ Features

-   Fully responsive design (desktop, tablet, mobile)
-   Sticky navigation & smooth scrolling
-   Hero section with image and text
-   Sections: Features, How it Works, Meals, Testimonials, Pricing, CTA
-   Mobile navigation toggle
-   Semantic and accessible HTML
-   Optimized images with WebP fallback

---

## 🛠 Technologies

-   HTML5 & CSS3 (Flexbox & Grid)
-   Google Fonts (Rubik)
-   Netlify (deployment)
